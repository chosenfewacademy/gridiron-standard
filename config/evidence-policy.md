# Evidence Policy

## Priority

1. Official NFL/team data and high-authority advanced performance sources
2. Established analytics/statistical sources
3. Credible film analysis and beat reporting
4. EA ratings, Madden testing, forums, Operation Sports, Reddit
5. Uncorroborated opinion

## Rules

- Fresh web research is mandatory for every Full Audit and Top 10 re-audit.
- At least one high-authority source is required.
- Use multiple independent sources whenever practical.
- Preserve conflicts instead of averaging them away.
- Record source publication/retrieval date.
- Re-check volatile data immediately before approval.
- Down-weight stale evidence when newer higher-quality evidence exists.
- Position-specific minimum evidence packages are required.
- If minimum evidence is not met, save the audit as INSUFFICIENT_EVIDENCE.

## Full Player Audit season context

Apply the application-derived NFL season phase before selecting primary performance evidence.
Never infer that regular-season production exists from the calendar year alone.

- OFFSEASON / PRESEASON: the most recently completed regular season is primary, with its postseason where applicable, multi-year context, and current role, roster/depth, injury/practice, participation, career, and system evidence.
- REGULAR_SEASON_EARLY: incorporate current games while retaining the completed-season primary baseline and explicit small-sample uncertainty.
- REGULAR_SEASON_ESTABLISHED: current regular-season performance is primary; previous seasons supply sustainability and trajectory context.
- POSTSEASON / COMPLETE_SEASON: the current NFL season's regular-season sample remains primary; postseason is a separate evidence sample.

Official calendar/schedule provenance and the applicable category schema are mandatory.
Missing calendar facts, required categories, primary-season evidence, source provenance, or material evidence coverage keep the gate closed.
Unavailable premium metrics require explicit public substitutes and confidence limitations, not omitted categories.
This evidence-stage gate does not approve audits, reconstruct locked controls, or define Madden OVR formulas.
